# キーマップ一覧と実装状況

Vy のモーダル編集で扱うキーと、その実装状況の一覧です。キー入力の設計は
[`ui.md`](./ui.md) の「キー入力の流れ」、実装の順序は
[`roadmap.md`](./roadmap.md) にあります。

現時点（Phase 1）は、キーマップ API ではなく
[`crates/vy-app/src/editor.rs`](../crates/vy-app/src/editor.rs)
の組み込みエンジンがキーを直接解釈します。Phase 2 で
`keymap.bind`（[`api.md`](./api.md) §10）へ移します。この文書は、移行の前後で
「どのキーを、どの意味で実装するか」を一か所にまとめるためのものです。

## 1. 状態の見方

| 表記     | 意味                                                                      |
| :------- | :------------------------------------------------------------------------ |
| 実装済み | 動く。`crates/vy-app/src/editor.rs` のテストで押さえている                |
| 一部     | 動くが、下の「制限」に書いた範囲だけ。カウントや行単位の操作は効かない    |
| 未実装   | 予定だけ。押しても何も起きない（Normal / Select）か、文字として入力される |

最終更新: 2026-10-22（Phase 1）。

## 2. 入力の経路

- Insert モードの文字は、キーマップではなく
  `EntityInputHandler`（`replace_text_in_range`）が受け取ります（
  [`ui.md`](./ui.md) §2）。
- Normal / Select
  モードでは、文字キーは組み込みエンジンが消費し、入力ハンドラへ渡しません。
- 認識するキー名は、文字キー（`a`〜`z`、記号、数字）と、`Left`、`Right`、`Up`、
  `Down`、`Home`、`End`、`Esc`、`Enter`、`Backspace`、`Tab`、`Space`、`Ctrl-r`、
  `Ctrl-u` です。`Alt` と `Super` 付きのキーは捨てます（macOS の `Option`
  入力は入力ハンドラ経由で文字になります）。
- 未実装のキーは、Normal / Select では無視されます。Insert
  では通常の文字入力になります。

## 3. 共通のプレフィックス

| キー           | 動作                             | 状態     | 制限                                                           |
| :------------- | :------------------------------- | :------- | :------------------------------------------------------------- |
| `1`〜`9`       | カウント。続く数字をつなげる     | 一部     | `u`、`Ctrl-r`、`i`、`a`、`v` では使わない（カウントを捨てる）  |
| `"` + `a`〜`z` | レジスタを選ぶ                   | 一部     | 削除だけが書き込む。ヤンク `y` と `+` / `*` は未実装           |
| `g` + `g`      | 先頭行へ。カウント付きはその行へ | 実装済み | `g` のあとに別のキーが来たら何もせずに終わる                   |
| `.`            | 直前の変更を繰り返す             | 一部     | 削除と Insert セッションのみ。貼り付けは Insert として記録する |

- カウントは `5x`、`3j`、`2gg`、`3G` のように使います。`0`
  はカウントの途中でのみ数字になります。
- `3.` のように、`.` にカウントを付けると変更をその回数だけ繰り返します。
  削除はカウントを掛けた範囲を一度に消します。
- `.` が繰り返す Insert は、`i` で入って `Esc`
  で抜けるまでの間に挿入した文字列です。途中の `Backspace` は差し引きます。

## 4. Normal モード

| キー           | 動作                               | 状態     | 備考                                                   |
| :------------- | :--------------------------------- | :------- | :----------------------------------------------------- |
| `h` / `Left`   | 左へ                               | 実装済み | カウント可                                             |
| `l` / `Right`  | 右へ                               | 実装済み | カウント可                                             |
| `j` / `Down`   | 下へ                               | 実装済み | カウント可。列は覚えておく                             |
| `k` / `Up`     | 上へ                               | 実装済み | カウント可。列は覚えておく                             |
| `w`            | 次の単語の先頭へ                   | 実装済み | カウント可。空白区切りのみ                             |
| `b`            | 前の単語の先頭へ                   | 実装済み | カウント可。空白区切りのみ                             |
| `e`            | 単語の末尾へ                       | 実装済み | カウント可。空白区切りのみ                             |
| `0` / `Home`   | 行頭へ                             | 実装済み |                                                        |
| `$` / `End`    | 行末の文字へ                       | 実装済み |                                                        |
| `gg`           | 先頭行へ（カウント付きはその行へ） | 実装済み |                                                        |
| `G`            | 最終行へ（カウント付きはその行へ） | 実装済み | `1G` は先頭行                                          |
| `x`            | カーソルの文字を削除               | 実装済み | カウント可。削除した文字はレジスタへ                   |
| `d`            | 選択を削除                         | 一部     | Normal ではカーソルからカウント文字。`dd` などは未実装 |
| `p`            | レジスタをカーソルの後ろに貼る     | 一部     | 文字単位のみ。行単位の貼り付けは未実装                 |
| `P`            | レジスタをカーソルの前に貼る       | 一部     | 文字単位のみ                                           |
| `i`            | 選択の先頭から Insert へ           | 実装済み |                                                        |
| `a`            | 選択の末尾から Insert へ           | 実装済み |                                                        |
| `v`            | Select モードへ                    | 実装済み |                                                        |
| `u`            | アンドゥ                           | 実装済み | 履歴はコアが持つ（ADR 0004）                           |
| `Ctrl-r`       | リドゥ                             | 実装済み |                                                        |
| `Ctrl-u`       | アンドゥ（別名）                   | 実装済み | `ui.md` の `pageUp` と衝突する。§10 を参照             |
| `Esc`          | Normal へ戻る（選択は 1 文字）     | 実装済み |                                                        |
| `"`、数字、`.` | §3 のプレフィックス                | 一部     |                                                        |

## 9. キーマップ API（Phase 2）

組み込みエンジンのキーを、Phase 2 で `keymap.bind`
による既定のキーマップへ移します。ここに載せたキーが、そのまま既定値になります。

| 項目                                                       | 状態   | 備考                                                    |
| :--------------------------------------------------------- | :----- | :------------------------------------------------------ |
| `keymap.bind(keys, target, options?)`                      | 未実装 | `when` でモードとフォーカスを判定する                   |
| `keymap.unbind(keys, options?)`                            | 未実装 | 利用者の上書きに使う                                    |
| `keymap.setContext(key, value)`                            | 未実装 | プラグイン独自の条件                                    |
| `keymap.registerMode(definition)`                          | 未実装 | 優先度 P2                                               |
| `keymap.sequenceTimeout`                                   | 未実装 | `g g` のような複数キーの待ち時間                        |
| カウントをアクションへ渡す方法                             | 未決定 | （[`ui.md`](./ui.md) §8）                               |
| `Insert` の予約キー（`Esc`、`Tab`、`Enter`、`Ctrl-Enter`） | 一部   | `Esc`、`Tab`、`Enter` は実装済み。`Ctrl-Enter` は未実装 |

## 10. 未決定事項

1. **`Ctrl-u` の意味**
   - エディタではアンドゥの別名として実装済みです。`ui.md` では `pageUp`
     に割り当てています。キーマップへ移すときに、どちらへ寄せるか決めます。
2. **カウントの受け渡し**
   - キーマップからアクションへカウントを渡す方法が未定です。組み込みエンジンの間は、
     エンジンが数字を解釈します。
3. **行単位の操作**
   - 削除と貼り付けは文字単位だけです。行単位（`dd`、`yy`、`p`）の意味と、
     レジスタの種類（文字単位 / 行単位）を決める必要があります。
4. **ヤンクの追加**
   - レジスタへ書き込む手段が削除だけなので、`y`
     を入れるまではレジスタが削除専用です。
5. **`Esc` の扱い**
   - `ui.md` では、Normal の `Esc`
     でウィジェットのフォーカスを外す予定です。エディタの `Esc`
     と競合しないよう、フォーカスの層を決めてから実装します。
