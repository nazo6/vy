# 仕様書一覧 (Living Specs)

Vy のシステム設計・仕様に関する「現在の唯一の正解（SSOT）」を管理するディレクトリです。
確定した現在の仕様のみを記述し、常に最新のコードベースに合わせてメンテナンスされます。
