# キーマップ一覧と実装状況

Vy のモーダル編集で扱うキーと、その実装状況の一覧です。キー入力の設計は
[`ui.md`](./ui.md) の「キー入力の流れ」にあります。

現時点は、`crates/vy-app/src/keymap.rs`
がキー列を照合し、`builtin/keymaps/default.json` の既定キーマップからコマンド ID
を決めます。`crates/vy-app/src/editor/`
はコマンドを実行するだけで、キーの解釈は持ちません。`init.ts` から `keymap.bind`
を呼ぶ経路も動きます。再評価のときは、`init.ts` が足した束縛だけを外します。

## 1. 状態の見方

| 表記     | 意味                                                                      |
| :------- | :------------------------------------------------------------------------ |
| 実装済み | 動く。`crates/vy-app/src/editor/` と `keymap.rs` のテストで押さえている   |
| 一部     | 動くが、下の「制限」に書いた範囲だけ。カウントや行単位の操作は効かない    |
| 未実装   | 予定だけ。押しても何も起きない（Normal / Select）か、文字として入力される |

最終更新: 2026-10-25（UI・エディタ改善サイクル完了）。

## 2. 入力の経路

- Insert モードの文字は、キーマップではなく
  `EntityInputHandler`（`replace_text_in_range`）が受け取ります（
  [`ui.md`](./ui.md) §2）。
- オーバーレイ（パレット / Ex など）の印字キーも、キーマップではなく
  `EntityInputHandler` が受け取ります。印字キーでは
  `stop_propagation` を呼ばないでください。macOS では止めると入力メソッド
  （`insertText`）に渡らなくなり、ABC 配列で文字が入らなくなります。
- 印字キー以外のオーバーレイのキーはキーマップを通ります（ADR 0024 Phase 3）。キーは
  `overlay` と `uiRole` の条件で `vy.ui.*` に解決し、解決しなかったキーだけが
  オーバーレイの組み込み処理へフォールバックします。これにより、パレットと Ex の
  `Esc`、`Enter`、`j`、`k`、`Tab`、`Backspace` を `keymap.bind` で別のキーへ
  割り当てられます。
- Normal / Select
  モードでは、文字キーはキーマップが照合して消費し、入力ハンドラへ渡しません。一致したコマンドだけを
  `crates/vy-app/src/editor/` が実行します。
- 認識するキー名は、文字キー（`a`〜`z`、記号、数字）と、`Left`、`Right`、`Up`、
  `Down`、`Home`、`End`、`Esc`、`Enter`、`Backspace`、`Delete`、`Tab`、
  `Shift-Tab`（`BackTab`）、`Space`、`Ctrl` + 英字（`Ctrl-r`、`Ctrl-d`、
  `Ctrl-w` など）です。`Alt` と `Super`
  付きのキーは捨てます（macOS の `Option`
  入力は入力ハンドラ経由で文字になります）。
- 未実装のキーは、Normal / Select では無視されます。Insert
  では通常の文字入力になります。

## 3. 共通のプレフィックス

| キー           | 動作                             | 状態     | 制限                                                           |
| :------------- | :------------------------------- | :------- | :------------------------------------------------------------- |
| `1`〜`9`       | カウント。続く数字をつなげる     | 実装済み | キーマップが保持し、コマンドへ `count` で渡す                  |
| `"` + `a`〜`z` | レジスタを選ぶ                   | 一部     | 削除とヤンクが書き込む。`+` / `*` は未実装                     |
| `g` + `g`      | 先頭行へ。カウント付きはその行へ | 実装済み | `g` のあとに別のキーが来たら何もせずに終わる                   |
| `.`            | 直前の変更を繰り返す             | 一部     | 削除と Insert セッションのみ。貼り付けは Insert として記録する |

- カウントは `5x`、`3j`、`2gg`、`3G` のように使います。`0`
  はカウントの途中でのみ数字になります。
- `3.` のように、`.` にカウントを付けると変更をその回数だけ繰り返します。
  削除はカウントを掛けた範囲を一度に消します。
- `.` が繰り返す Insert は、`i` で入って `Esc`
  で抜けるまでの間に挿入した文字列です。途中の `Backspace` は差し引きます。

| `:`                 | Ex コマンドラインを開く    | 実装済み | Normal / Select。`e`、`w`、`sp`、`vsp`、`close`、`q` など                                                                                        |

スクロール位置、カーソル、選択、モードはペインごとに独立しています。同じ文書を
複数のペインで開いても干渉しません。最後に選択した範囲だけは文書ごとに覚え、
`g v`
でどのペインからでも復元できます（[ADR 0003](../adr/0003-editor-state.md)）。

コマンドパレットは `Space` で開きます。コマンド名と ID を単語単位で絞り込み、
`Up` / `Down`（`Ctrl-p` / `Ctrl-n`）で選び、`Enter` で実行、`Esc` で閉じます。
カテゴリの見出しと Ex 名を表示し、引数が必要なコマンドは選択後に1行の入力欄か
ピッカーで引数を取ります。入力は Ex と同じテキストエンジンを使い、IME の前編集に
も対応しています。

`:` で開く Ex コマンドラインの文法、別名、範囲、補完は
[`commands.md`](./commands.md) にまとめました。パレットと同じ実行層を使い、 `:`
はペインではなくオーバーレイとして開きます。

## 7.1 `when` のコンテキスト

既定キーマップのエディタ系バインドは `paneKind == 'editor'` を含みます。これにより、UI ペインにフォーカスがある間はエディタのキーが一致しません。値の一覧と設定する層は [`ui.md`](./ui.md) §2.1 にあります。

| コンテキスト       | 値                                                                       | 状態     |
| :----------------- | :----------------------------------------------------------------------- | :------- |
| `paneKind`         | `editor`、`ui`、`webview`、`terminal`                                    | 実装済み |
| `viewType`         | ビューの ID。エディタペインでは空文字                                    | 実装済み |
| `uiRole`           | `list`、`tree`、`table`、`textInput`、`button`。無ければ未設定           | 実装済み |
| `uiFocus`          | フォーカス中のノードの `id`                                              | 実装済み |
| `overlay`          | `none`、`palette`、`picker`、`ex`、`prompt`、`approval`、`settings` など | 実装済み |
| `surfaceId`        | 最前面のサーフェスの `id`                                                | 実装済み |
| `uiSelectionCount` | 選択中の項目数                                                           | 一部     |

- `overlay` は `none` 以外のとき、どのオーバーレイが開いているかを表します。パレットのうちプラグインが `ui.picker.show` で開いたものは `picker`、ホストのコマンド一覧と文書一覧は `palette` です。設定の選択と設定の入力は `settings` にまとめます。
- `Tab` と `Shift-Tab` は、UI ペインで `vy.ui.focus_next` / `vy.ui.focus_prev` に解決します。ウィジェットにフォーカスがある間はフォーカス移動になり、エディタペインではキーマップ上のほかの束縛へ流れます（[ADR 0024](../adr/0024-keyboard-first-plugin-ui.md) §3）。

### 7.2 `vy.ui.*` の既定キー

| キー                    | コマンド                                | 条件                        | 動作                         |
| :---------------------- | :-------------------------------------- | :-------------------------- | :--------------------------- |
| `j` / `Down` / `Ctrl-n` | `vy.ui.next`                            | `uiRole == 'list'` など     | カーソルを次へ               |
| `k` / `Up` / `Ctrl-p`   | `vy.ui.prev`                            | `uiRole == 'list'` など     | カーソルを前へ               |
| `Ctrl-d`                | `vy.ui.page_down`                       | `uiRole == 'list'` など     | 1 ページ進む                 |
| `Ctrl-u`                | `vy.ui.page_up`                         | `uiRole == 'list'` など     | 1 ページ戻る                 |
| `g g`                   | `vy.ui.first`                           | `uiRole == 'list'` など     | 先頭へ                       |
| `G`                     | `vy.ui.last`                            | `uiRole == 'list'` など     | 末尾へ                       |
| `l`                     | `vy.ui.expand`                          | `uiRole == 'tree'`          | 展開する                     |
| `h`                     | `vy.ui.collapse`                        | `uiRole == 'tree'`          | 折りたたむ                   |
| `Enter`                 | `vy.ui.activate`                        | `uiRole == 'list'` など     | 決定する                     |
| `x`                     | `vy.ui.toggle`                          | `uiRole == 'list'` など     | マークする／展開を切り替える |
| `y`                     | `vy.ui.yank`                            | `uiRole == 'list'` など     | 項目のテキストをコピー       |
| `Tab` / `Shift-Tab`     | `vy.ui.focus_next` / `vy.ui.focus_prev` | `uiRole` がある             | 次のフォーカス可能ノードへ   |
| `Esc`                   | `vy.ui.cancel`                          | `overlay == 'palette'` など | 一時状態を戻す／閉じる       |

エディタ系のバインドは `paneKind == 'editor' && overlay == 'none'` を条件に含みます。同じキー列が両方に一致しないよう、条件で排他にしています。

### 7.3 サーフェスのキー

開いているサーフェスは、入力を insert モードとしてキーマップへ渡します。印字キー以外はキーマップの既定バインドで処理します。

| サーフェス | キー                                          | コマンド                                      | 動作                   |
| :--------- | :-------------------------------------------- | :-------------------------------------------- | :--------------------- |
| 共通       | `Backspace`                                   | `vy.ui.delete_char`                           | 入力を 1 文字削除      |
| 共通       | `Ctrl-u`                                      | `vy.ui.clear_input`                           | 入力を空にする         |
| 共通       | `Esc`                                         | `vy.ui.cancel`                                | 一時状態を戻す／閉じる |
| Ex         | `Enter`                                       | `vy.ui.activate`                              | 実行する               |
| Ex         | `Up` / `Ctrl-p`                               | `vy.ui.history_prev`                          | 履歴を 1 つ前へ        |
| Ex         | `Down` / `Ctrl-n`                             | `vy.ui.history_next`                          | 履歴を 1 つ後ろへ      |
| Ex         | `Tab` / `Shift-Tab`                           | `vy.ui.complete_next` / `vy.ui.complete_prev` | 補完候補を巡回する     |
| 一覧系     | `j` / `k` / `g g` / `G` / `Ctrl-d` / `Ctrl-u` | `vy.ui.next` など                             | 一覧のカーソル移動     |
| 一覧系     | `Enter`                                       | `vy.ui.activate`                              | 選択を確定する         |
| 一覧系     | `x` / `y`                                     | `vy.ui.toggle` / `vy.ui.yank`                 | マークする／コピーする |

`:` は `mode != 'insert' && overlay == 'none'` のときだけ Ex を開きます。サーフェス内では入力中の文字として扱います。パレットのヒント行はキーマップから生成するため、`vy.ui.activate` を別のキーへ割り当てるとヒントも変わります。キーマップが解決しなかったキーは、オーバーレイの組み込み処理へフォールバックします。

## 8. キーマップ API

既定キーは [`builtin/keymaps/default.json`](../../builtin/keymaps/default.json)
にあり、`crates/vy-app/src/keymap.rs` が照合します。`init.ts` からは `vy-js`
のシム経由で同じキーマップを操作します。

| 項目                                           | 状態     | 備考                                                                            |
| :--------------------------------------------- | :------- | :------------------------------------------------------------------------------ |
| `keymap.bind({ keys, command, when?, args? })` | 実装済み | 後から登録したものが優先。`when` で条件を付ける。`args` は `ArgSpec` で検証する |
| `keymap.unbind({ keys })`                      | 実装済み | 一致するキー列をすべて外す（既定の束縛も対象）                                  |
| `keymap.setContext({ key, value })`            | 実装済み | `when` から参照できる。真偽値・文字列・数値                                     |
| `keymap.sequenceTimeout`                       | 実装済み | `editor.sequenceTimeoutMs`。既定 1000ms                                         |
| カウントをアクションへ渡す方法                 | 決定済み | コマンドへ `args.count` で渡す                                                  |
| レジスタ                                       | 決定済み | `args.register`。文字単位と行単位を持つ                                         |
| `Insert` の予約キー（`Esc`、`Tab`、`Enter`）   | 実装済み | 前編集の確定とモード遷移を処理                                                  |

`init.ts`
を再評価すると、そのスクリプトが足した束縛だけを外します。既定のキーマップは
残ります。`commands.registerCommand` で登録したコマンドも同じ単位で外れます。

  `crates/vy-app/src/editor/` と `crates/vy-app/src/keymap.rs`
