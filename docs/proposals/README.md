# 提案・検討メモ (Proposals)

まだ決まっていないアイデアや未決定事項、今後の実装フェーズ計画を置く場所です。
仕様書（`docs/specs/`）を「現在の確定仕様」だけに保つため、「これからどうするか悩んでいること」や「未実装機能の計画」はここに集約します。

## 運用ルール

個人開発のため、厳密なフローは設けません。

1. **書く**: 悩んでいることや設計案を思いついたら、ファイルを作ってメモします（`status: "open"`）。
2. **決まったら**:
   - 設計方針が決まったら ADR（`docs/adr/`）や仕様書（`docs/specs/`）に反映します。
   - この提案ファイルは `status: "closed"` にするか、役目を終えたら削除しても構いません。

## 命名規則

ファイル名は `NNNN-<short-title>.md` とします（例: `0001-phase-6-remote-plugins.md`）。
