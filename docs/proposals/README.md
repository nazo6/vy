# 提案・検討メモ (Proposals)

まだ決まっていないアイデアや未決定事項、設計の検討メモを置く場所です。
仕様書（`docs/specs/`）を確定仕様だけに保つため、「これからどうするか悩んでいること」はいったんここに書き出します。

## 運用ルール

個人開発のため、厳密なフローは設けません。

1. **書く**: 悩んでいることや設計案を思いついたら、ファイルを作ってメモします（`status: "open"`）。
2. **決まったら**:
   - 設計方針が決まったら ADR（`docs/adr/`）や仕様書（`docs/specs/`）に反映します。
   - この提案ファイルは `status: "closed"` にするか、役目を終えたら削除しても構いません。

## 命名規則

ファイル名は `NNNN-<short-title>.md` とします（例: `0001-remote-session.md`）。

## テンプレート

```yaml
---
id: "0001"
title: "提案のタイトル"
type: "proposal"
status: "open" # "open" (検討中) | "closed" (決定・対応済み)
date: 2026-10-25
---
```

```markdown
# [Proposal] タイトル

## 背景・課題
- 何に困っているか、なぜ考えたいか

## 検討中のアイデア・案
- 考えられるやり方やメモ

## 決めること・論点
- 決めないといけないポイント
```
