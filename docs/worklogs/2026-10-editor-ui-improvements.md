# [Worklog] UI・エディタ品質改善ログ

画面と編集の正しさ、使い勝手、パフォーマンスを向上させるために実施した改善作業の記録です。

---

## 1. 正しさと安全性 (P0)

- [x] **未保存文書の確認**: `vy.pane.close` 時に未保存の変更がある場合は確認を挟むように修正。強制終了 `:q!` に対応。
- [x] **表示セル幅の計算**: UTF-16 コード単位ではなく表示セル数で数えるように修正。全角文字やタブを含む行の折り返し幅、横スクロール、ホバー座標のずれを解消。
- [x] **IME 候補位置**: スクロール量や折り返しのサブ行を考慮して IME 候補ウィンドウの位置を返すように修正。
- [x] **パレットと Ex コマンドラインの IME 対応**: キーイベントの直接取得から IME 前編集に対応し、日本語の入力と検索を可能にした。

---

## 2. 表示と操作の質 (P1)

- [x] **カーソル表示**: 点滅、Select 系のカーソル形状、現在行ハイライトを実装。
- [x] **ステータスライン**: 長いファイルパス・URI の切り詰め表示（ellipsis）対応。
- [x] **通知**: `notifications.show` で表示された通知の自動消去と重なり処理を実装。
- [x] **テーマ**: `Theme::dark()` 固定から、設定に応じた `Theme::light()` 切り替えと動的再描画に対応。
- [x] **タブ文字表示**: `tabstop` 設定に基づいたセル幅での展開描画に対応。
- [x] **ガター**: 実測した文字幅に合わせ、1行に複数マークを描画可能に修正。
- [x] **ホバー**: 折り返しサブ行と全角幅を正確に計算した位置にポップアップを表示。
- [x] **横スクロール**: 行の最大長に応じた上限設定と、文書切り替え・再同期時のリセット処理。

---

## 3. 性能と保守 (P2)

- [x] **メモリ・クローン削減**: 描画フレームごとの `Config` と `Theme` のクローンを廃止し、参照 / `Arc` 共有化。
- [x] **行折り返し計算の最適化**: 長い 1 行を含むファイルで毎フレーム O(行長) になっていた `chunk_line` を、可視行のみの差分計算とキャッシュ化。
- [x] **文字幅測定キャッシュ**: フォント設定ごとに測定結果をキャッシュし、毎フレームの再測定オーバーヘッドを削減。
- [x] **アクセシビリティ・キー操作**: `Esc` のフォーカス層順序（モーダル -> ウィンドウ）を整理。
