# ADR 0029: エディタ操作・キーマップ・UI拡張

- 状態: 提案中 (proposed)
- 日付: 2026-10-25
- カテゴリー: feature

既存の仕様書（`docs/specs/*.md`）から抽出した、モーダル編集キー、コマンド、UI の未実装機能および未決定事項のまとめです。決定済みの事項は先行する ADR を参照し、ここには未着手の作業と未決定の論点、作業計画をまとめます。

決定済みで未着手のもの:

- `Esc` のフォーカス層とモード遷移は [ADR 0024](./0024-keyboard-first-plugin-ui.md) で決定済みです。

---

## 1. 未実装のモーダル編集キー (`keymap.md` より)

現在 Normal / Insert モードの基本動作とテキストオブジェクトは実装済みですが、以下のキーが未実装です。

- **挿入の起点**: `gi`
- **変更系**: `c`、`s`、`S`、`r`、`R`、`~`、`J`、`>`、`<`、`Ctrl-a`、`Ctrl-x`
- **移動系**: `W`、`B`、`E`、`ge`、`f`、`t`、`;`、`,`、`%`、`{`、`}`、`(`、`)`、`H`、`M`、`L`、`Ctrl-f`、`Ctrl-b`
- **1行スクロール**: `Ctrl-e` / `Ctrl-y`
- **インデント計算**: Insert モードでの `Tab`
- **マクロ**: `q`、`@`、`@@`
- **モード登録 API**: `keymap.registerMode(definition)`

## 2. コマンド・Ex コマンドラインの未実装・論点 (`commands.md` より)

- **未実装コマンド**:
  - `:wq` (`vy.document.write_quit`)
  - `:bn` / `:bp` (`vy.document.next` / `previous`)
- **最後のペインでの `:q` の挙動**:
  - アプリ全体を終了するか、エラーとして拒否するか（ウィンドウを閉じるか確認するか）。
- **履歴の共有**:
  - コマンドパレットの履歴と Ex コマンドラインの履歴を共有するか別個にするか。

## 3. 未決定事項 (`ui.md`, `panes.md` より)

- **ステータスラインの表示モード**:
  - ペインごとのステータスラインと、グローバルステータスラインの切り替え（`ui.statusline.mode: "global" | "per-pane" | "none"`）。
- **フローティングペイン**:
  - ウィンドウ分割ツリーから独立したオーバーレイペイン（`layout/set`、ポップアップ端末など）。
- **比率の表現**:
  - ペインの比率を絶対ピクセルで持つか、相対比率で持つか（ウィンドウリサイズ時の挙動）。

## 4. システム・環境対応 (`api.md`, `layout.md` より)

- **改行コード (CRLF / LF)**:
  - `document.eol` と `document.setEol` の導入時期、Windows 環境での改行コード自動判定と保持。
- **セッション永続化 (`session.json`)**:
  - ウィンドウサイズ、スクロール位置、フォーカス履歴の保存と次回起動時の復元。
- **システムクリップボード連携**:
  - `"+` / `"*` レジスタを通じた OS クリップボードとのやり取り。
- **マウス操作の拡張**:
  - クリックによるカーソル移動、ドラッグによる選択範囲作成、非アクティブペインのホイールスクロール。
  - 実装済み（2026-10-30、[worklog](../worklogs/2026-10-30-mouse-pane-and-cursor.md)）。
